## Где ИИ мог ошибиться?
- Часть демо-данных (помеченные `~` в исходных материалах) — расчётные оценки, не из
  первичных аудированных отчётов. Требуют проверки по PDF с KASE.
- Нормативные пороги коэффициентов (например, Current Ratio > 1.5) — общие отраслевые нормы,
  не специфичные для телекоммуникационного сектора Казахстана. Рекомендуется уточнить
  отраслевые бенчмарки.
- Прогнозная модель (Блок 4) упрощённая (top-down), не учитывает все взаимосвязи между
  отчётами (не является полной 3-statement model).
