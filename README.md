# Финансовый анализ — АО «Казахтелеком»

Веб-приложение для анализа финансовой отчётности по методологии:
**Отчётность → Качество → Анализ → Прогноз → Вывод**

Индивидуальный проект. Студентка: Мадина. Компания: АО «Казахтелеком» (KASE: KZTK).

## Что делает приложение

Приложение позволяет вручную ввести финансовые данные компании (выручка, прибыль, активы,
обязательства, денежные потоки) за 5 лет и автоматически рассчитывает:

- **Коэффициенты ликвидности** — Current Ratio, Quick Ratio, Cash Ratio
- **Коэффициенты прибыльности** — ROE, ROA, Gross/EBIT/EBITDA/Net Margin
- **Долговую нагрузку** — Debt/Equity, Debt/Assets, Net Debt/EBITDA, Interest Coverage
- **Эффективность** — Asset Turnover, Receivables Turnover, DSO
- **Денежный поток** — CFO/Net Income, FCF, FCF Margin
- **Quality Scorecard** — проверка качества отчётности (арифметика баланса, качество прибыли)
- **Прогноз на 3 года** — Base case и Stress case с настраиваемыми допущениями
- **Структурированный вывод** — факты, а не инвестиционные рекомендации

Приложение **переиспользуемо**: можно очистить демо-данные и ввести данные любой другой
компании — расчёты не сломаются, логика останется той же.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <ссылка-на-репозиторий>
cd kazakhtelecom-financial-analysis
```

### 2. Установить зависимости

Требуется Python 3.9+

```bash
pip install -r requirements.txt
```

### 3. Запустить приложение

```bash
streamlit run app/main.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## Как пользоваться

1. Откройте раздел **«1️⃣ Отчётность (Input)»**
2. Нажмите **«📥 Загрузить демо-данные Казахтелекома»** в боковой панели — чтобы увидеть пример
3. Или введите данные вручную по вкладкам годов (2020–2024)
4. Перейдите в раздел **«2️⃣ Качество отчётности»** — проверка качества данных
5. Перейдите в **«3️⃣ Финансовый анализ»** — все коэффициенты с графиками
6. Перейдите в **«4️⃣ Прогноз»** — настройте допущения для Base/Stress сценариев
7. Перейдите в **«5️⃣ Вывод»** — итоговый структурированный вывод

## Input-файл

В папке `data/` находится `kazakhtelecom_sample.csv` — пример структурированных входных
данных. Приложение принимает ввод через интерфейс (число-инпуты), PDF-парсинг не реализован
(возможное расширение для бонусных баллов).

## Источники данных

Демо-данные взяты из публичных источников: KASE (kase.kz), годовые отчёты Казахтелекома
2020–2024, Kursiv.media, Kapital.kz, Profit.kz. Полный список — в `data/sources.md`.

## Ограничения анализа

- Часть строк ОДС (CFO, CFI, CFF, Capex, дивиденды) не заполнена в демо-данных в полном
  объёме — требует извлечения из аудированных PDF-отчётов KASE
- Данные 2024 года представлены без учёта ТОО «Мобайл Телеком-Сервис» (продано в январе 2025) —
  несопоставимы напрямую с 2023 годом без restated данных
- Прогноз построен по упрощённой top-down модели, не является полной linked 3-statement model

## Дисклеймер

Приложение **не выдаёт инвестиционных рекомендаций** («покупать / продавать / держать»).
Оно показывает факты, зоны проверки качества данных, динамику и сценарии прогноза.
